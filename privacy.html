Privacy Policy

Last updated: November 26, 2026

Jagstar Auto Pilot ("the tool") is a private desktop tool used only by the owner of the YouTube channel Jagstar (@jagstargaming) to upload and schedule their own gaming videos.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. YouTube is operated by Google; see the Google Privacy Policy at https://policies.google.com/privacy.

Information the tool accesses

  • The tool requests only the https://www.googleapis.com/auth/youtube.upload permission.
  • It uses that permission to upload video files and set each video's title, description, tags, category, privacy status and scheduled publish time on the owner's own channel.
  • It does not read, collect or store any information about other YouTube users, viewers, comments or channels.

How information is used, stored and shared

  • Use: solely to upload and schedule the owner's own videos.
  • Storage: the Google sign-in (OAuth) token is stored only on the owner's personal computer. Video files and their metadata stay on that computer until uploaded to YouTube. No data is stored on any server operated by the tool.
  • Sharing: no data is sold, rented or shared with any third party. Data is sent only to YouTube/Google through the YouTube API.
  • Cookies and tracking: the tool and this website do not use cookies, analytics or tracking.

Deleting data and revoking access

  • Access can be revoked at any time through the Google security settings page: https://myaccount.google.com/permissions.
  • Deleting the stored token file from the owner's computer removes all locally stored authorization data immediately.
  • Any locally stored API data is deleted or refreshed within 30 days, in line with the YouTube API Services Developer Policies.
  • Videos already uploaded can be deleted at any time in YouTube Studio.

Children

The tool is not directed at children and is used only by the channel owner.
